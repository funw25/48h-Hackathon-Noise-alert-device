# 项目简介：静音小卫 —— 桌面噪音提醒装置


**静音小卫** 是一个面向图书馆、自习室等安静学习环境的桌面噪音提醒装置。通过实时声音检测、LCD数值显示、红蓝LED反馈及物理按钮确认，帮助用户在不尴尬的情况下意识到自己无意中发出的噪音，并即时纠正。

## 📖 项目背景

在需要高度集中注意力的学习环境中，学生可能会无意中发出噪音（如翻书声过响、拖动椅子、咳嗽、耳机漏音、手机提示音等），干扰他人学习。传统的提醒方式（拍肩、写纸条、口头指责）比较尴尬且不及时。

我们希望通过一个**非侵入、不尴尬的物理装置**，在用户发出超标噪音时即时提醒，帮助其自觉保持安静。

## 🎯 核心功能

- **实时噪音检测**：采用 MAX9814 高灵敏度麦克风模块，采集环境声音峰值。
- **LCD 实时显示**：16x2 LCD 屏幕显示当前音量数值及系统状态（等待/红灯提醒/蓝灯确认）。
- **红/蓝 LED 反馈**：
  - 音量超过阈值且持续 300ms → 红色 LED 亮起，提示“噪音超标”
  - 用户按下按钮确认 → 红色 LED 熄灭，蓝色 LED 亮起 5 秒，表示“已确认提醒”
- **防误触发算法**：采用峰值检测 + 持续时间滤波，避免瞬时噪声或呼吸声误触发。
- **状态机管理**：确保在红灯或蓝灯亮起期间不会重复触发，逻辑清晰稳定。

## 🔧 电路连接

| Arduino 引脚 | 连接组件 |
|--------------|----------|
| A0 | MAX9814 模拟输出 |
| 3 | 红色 LED 正极（串联 220Ω 电阻） |
| 4 | 蓝色 LED 正极（串联 220Ω 电阻） |
| 2 | 轻触按钮（另一端接 GND，使用 INPUT_PULLUP） |
| 5V / GND | 为传感器、LCD 供电 |
| I2C (A4/A5) | LCD1602 I2C（SDA → A4， SCL → A5） |

## 💻 代码结构

代码基于 Arduino 框架编写，核心逻辑如下：

```cpp
- 包含 Wire.h 和 LiquidCrystal_I2C.h 驱动 LCD
- 定义引脚及可调参数（阈值、持续时间、蓝灯保持时间）
- setup(): 初始化引脚、LCD 启动画面、串口调试
- loop(): 
  1. 峰值采样（50ms 窗口）获取 maxVal
  2. 更新 LCD 第一行显示 "Vol:xxxx"
  3. 根据状态更新 LCD 第二行（Waiting / RED ON - Press! / BLUE ON - OK）
  4. 噪音检测：若红灯、蓝灯均未亮且 maxVal 超过阈值并持续 300ms，则亮红灯
  5. 按钮检测：红灯亮时按下按钮，熄灭红灯，亮蓝灯并计时 5 秒
  6. 蓝灯计时结束自动熄灭，系统恢复待机
